# 乘法戰機大比拼

三年級數學互動網頁：三欄同時玩，敵人由畫面頂部持續往下跌，答對乘法開火擊落。

## 點樣開

1. 用瀏覽器打開 `index.html`（雙擊即可，可離線）。
2. 課堂：接電子白板／投影機，建議全螢幕（F11）。
3. 託管：部署到 [GitHub Pages](https://pages.github.com/)，或把資料夾拖到 [Netlify Drop](https://app.netlify.com/drop)。網站根目錄就是這個 `index.html`，無需建置。

**English:** Open `index.html` in a browser, or host this folder on GitHub Pages or Netlify Drop. The site root is the single HTML file — no build step.

## 點玩

三人在電子白板（Smart Board）上同時玩，每欄獨立觸控。沒有生命值：答錯或敵人逃走都不會出局。這是限時計分賽，時間到後一起看排行榜。

1. 設定三欄名稱、難度、比賽時間 →「開始遊戲」
2. 倒數後，每欄敵人由**上方**持續跌向底部戰機
3. 學生撳自己欄嘅答案（簡單四選一、進階六選一、挑戰九宮格；支援多人同時觸控）
4. **答對** → 戰機瞄準再開火；得分＝基礎分＋快答加成＋連擊加成
5. **答錯** → 溫柔顯示正確答案、斷連擊，快速換下一題（唔出局）
6. **敵人跌到底** → 逃走只扣少少分／斷連擊，繼續玩
7. **時間到** → 一齊睇排行榜（分數／答對數／最高連擊）

## 進階

- **連擊變身**：連續答對 3／5／8 → 火焰型（更快更粗）／穿甲型（穿透 2 個）／究極型（三連射 + 爆炸）
- **斷連擊**：答錯或敵人逃走會重置連擊
- **功能卡**（偶爾出現，撳即用）：雙激光、慢動作、清場炸彈、護盾

## 題目範圍

| 選項 | 乘法範圍 | 下落速度 |
|------|----------|----------|
| 簡單 | 1–5 | 慢 |
| 普通 | 1–9 | 中（預設） |
| 挑戰 | 1–9 + 偶有 ×0 | 快 |

## 答題難度

| 選項 | 點樣答 |
|------|--------|
| 簡單 | 四選一（原本玩法） |
| 進階 | 六選一，干擾答案更接近 |
| 挑戰 | 沒有選擇，每欄自己的九宮格鍵盤（1–9、0、刪、確定），三欄可同時撳 |

分數顯示係疊在戰場上的大號發光數字，加分會有＋N 同連擊閃光；唔會撐大或擠壓畫面。
