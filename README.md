# 數感戰機

三年級數學 Smart Board 計時賽。三欄一齊玩，敵人由畫面頂部持續往下跌，答對就瞄準開火。打開 `index.html` 即可玩，無需建置。

玩法有三種，開始畫面揀一種：

- **乘法表**：計乘法，四選一
- **單位**（單位特工）：睇物件或情景，揀合適長度單位 mm／cm／m／km
- **五位數**（五位數擂台）：比較兩個五位數（＞ ＜ ＝），或者搵出萬位數字

## 點樣開

1. 用瀏覽器打開 `index.html`（雙擊即可，可離線）。
2. 課堂：接電子白板／投影機，建議全螢幕（F11）。
3. 託管：部署到 [GitHub Pages](https://pages.github.com/)，或把資料夾拖到 [Netlify Drop](https://app.netlify.com/drop)。網站根目錄就是這個 `index.html`，無需建置。

**English:** Open `index.html` in a browser, or host this folder on GitHub Pages or Netlify Drop. The site root is the single HTML file — no build step. The game is 數感戰機, with multiplication, length-unit, and 5-digit modes.

## 點玩

三人在電子白板（Smart Board）上同時玩，每欄獨立觸控。沒有生命值：答錯或敵人逃走都不會出局。這是限時計分賽，時間到後一起看排行榜。

1. 揀玩法（乘法表／單位／五位數）、三欄名稱、難度、比賽時間 →「開始遊戲」
2. 倒數後，每欄敵人由**上方**持續跌向底部戰機
3. 學生撳自己欄嘅選擇題（支援多人同時觸控）
4. **答對** → 戰機瞄準再開火；得分＝基礎分＋快答加成＋連擊加成
5. **答錯** → 溫柔顯示正確答案、斷連擊，快速換下一題（唔出局）
6. **敵人跌到底** → 逃走只扣少少分／斷連擊，繼續玩
7. **時間到** → 一齊睇排行榜（分數／答對數／最高連擊）

## 進階

- **連擊變身**：連續答對 3／5／8 → 火焰型（更快更粗）／穿甲型（穿透 2 個）／究極型（三連射 + 爆炸）
- **斷連擊**：答錯或敵人逃走會重置連擊
- **功能卡**（偶爾出現，撳即用，浮在畫面上面）：雙激光、慢動作、清場炸彈、護盾
- 戰機同敵人按畫面高度比例縮放，投影到大白板仍然細小；分數同功能卡浮在畫布上，唔會擠走賽道

## 難度

難度同時影響敵人下落速度，同埋題目深淺。

| 選項 | 乘法表 | 單位 | 五位數 | 下落 |
|------|--------|------|--------|------|
| 簡單 | 1–5 | 好明顯的例子 | 萬位或千位差好遠 | 慢 |
| 普通 | 1–9 | 日常物件 | 比較百／十位，或搵萬位 | 中（預設） |
| 挑戰 | 1–9 + 偶有 ×0 | 易混淆例子 | 個位好接近，偶有相等 | 快 |
